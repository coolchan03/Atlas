# GenieX (Qualcomm): removed from the app

GenieX was tried and removed in 0.0.213. It is text-only (no tools, vision or MTP), runs on two chips (Snapdragon 8 Elite and Elite Gen 5), adds 89 MB, and costs build time. Nothing from it is in the source, the dependencies or the APK, and the build has no flag for it.

If it is reconsidered, the last version that had the bridge, the engine and the comparison card is 0.0.212 (git history, commit before "Remove GenieX"). The licence notes then were: SDK BSD 3-Clause plus Qualcomm Terms of Use, no fee stated; the bundled runtime libraries' redistribution terms had to be confirmed first.
